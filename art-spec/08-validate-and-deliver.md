# 08 · ตรวจเองก่อนส่ง และลำดับการส่งงาน

## ตรวจด้วย compiler (ต้องมี manifest แล้ว)

```powershell
# 1) build ภาพของตัวเองแทน fixture (ภาพจะไปอยู่ที่ public/uvce-compiled)
node tools/uvce/build-assets.ts --src art-input/knight --out public/uvce-compiled

# 2) เปิดดูในแอป (ห้ามใช้ pnpm dev เพราะจะสร้าง fixture ทับภาพของเรา)
pnpm exec vite
#    แล้วเปิด http://localhost:5173/  และ  http://localhost:5173/?scene=studio  (กล้องตรง 1 px = 1 px)

# 3) ภาพ contact sheet ทุกทิศ ทุกท่า (ต้องใช้ id แบบตัวต้นแบบ ดู 07)
node tools/uvce/contact-sheet.ts --out art-input/knight-contact-sheet.png

# 4) เสร็จแล้วสร้าง fixture กลับคืน
pnpm assets
```

ถ้าผ่าน จะเห็นบรรทัดประมาณ `[assets:build] m-…: N items, … source frames -> … unique images …, 0 warnings`
ถ้าไม่ผ่าน จะขึ้น `[assets:build] FAILED:` พร้อมรายการปัญหา ซึ่งระบุไฟล์และตำแหน่งใน manifest

## ข้อความ error ที่อาจเจอ

| code | ความหมาย | วิธีแก้ |
|---|---|---|
| `png.size` | ไฟล์ไม่ใช่ 256×256 | export เต็มผ้าใบ ไม่ crop ไม่ scale |
| `png.no-alpha` | ไม่มีช่อง alpha | export เป็น PNG RGBA (Transparency ✔) |
| `png.depth` | ไม่ใช่ 8 bit ต่อช่อง | export 8-bit |
| `png.blank` | ภาพว่างเปล่า | ลบไฟล์นั้นออกจาก manifest (เช่นทิศที่มองไม่เห็น) |
| `png.matte` | ขอบผ้าใบติดพื้นหลัง | ลบพื้นหลัง |
| `png.touches-border` | (เตือน) ภาพแตะขอบผ้าใบ | ขยับเข้ามาในพื้นที่ปลอดภัย |
| `part.frame-count` | จำนวนเฟรมไม่ตรงกับท่า | idle และ walk ต้องมี 8 เฟรมพอดีทุกทิศที่ส่ง |
| `frame.sockets` | body ขาด socket หรือชิ้นอื่นมี socket | ใส่ครบ 6 จุดเฉพาะ body |
| `frame.anchor` | ชิ้นที่เกาะ socket ไม่มี anchor | ใส่ anchor = socket ท่าพักของทิศนั้น |
| `part.layer` | layer ไม่ตรงกับ slot | ดูตาราง slot ใน 03 |
| `part.attach` | ชื่อ socket ผิด | ใช้ชื่อตาม 03 |
| `item.duplicate` | id ซ้ำ | เปลี่ยน id |
| `item.atlas-group` | ใน atlas group เดียวกันมี filter หรือ mip ต่างกัน | ใช้ค่าเดียวกันทั้งกลุ่ม |

## ตรวจด้วยตา (หลัง build ผ่าน)

- [ ] หมุนกล้องรอบตัว: ภาพเปลี่ยนทิศถูกต้อง ไม่กระโดดตำแหน่ง เท้าอยู่ที่เดิม
- [ ] ท่าเดิน: เท้าไม่ไถล หมวก หัว ผม และอาวุธติดตามตัวทุกเฟรม ไม่ลอยหรือหลุด
- [ ] ถอดชิ้นทีละชิ้น (เลือก none ใน panel): ไม่มีรูโหว่บน body ใต้ชุดหรือใต้ผม
- [ ] ทิศหลัง: ผมด้านหลังทับหัว ไม่เห็นหน้าม้าโผล่
- [ ] อาวุธอยู่หน้าตัวใน S/SE/E/NE และหลังตัวใน N
- [ ] ไม่มีขอบขาวหรือดำรอบภาพ (ดูบนพื้นหลังสีเข้มในฉาก stage)
- [ ] ตัวละครยืนบนพื้นพอดี ไม่ลอย ไม่จม

## ลำดับการส่งงาน (แนะนำให้ส่งเป็นรอบ)

| รอบ | ส่งอะไร | เหตุผล |
|---|---|---|
| **1. ทดลอง** | body idle เฉพาะ **S และ SE** (8 เฟรมต่อทิศ + socket), head, ผม 1 ทรง, armor 1, hat 1, weapon 1 เฉพาะ S และ SE | เช็คสัดส่วน ตำแหน่ง การแยกชั้น และ socket ก่อนลงแรงวาดครบ (ตรงกับแผน Mode B ใน blueprint) |
| **2. ครบทิศ** | ทุกชิ้นของรอบ 1 ให้ครบ 5 ทิศ (N NE E SE S) | เช็คการหมุนและลำดับชั้นทุกทิศ |
| **3. ท่าเดิน** | body + arm_front walk ครบ 5 ทิศ พร้อม socket | เช็คการเคลื่อนไหวและการติดตามของชุด |
| **4. ตัวเลือกชุด** | ผม เกราะ หมวก อาวุธ แบบอื่นๆ (ชิ้นละ 5 ทิศ) | หลังจาก rig นิ่งแล้ว ชิ้นใหม่วาดง่าย ไม่ต้องแก้ body |

หลังแต่ละรอบ ผมจะ build, ตรวจ parity, ทำภาพ contact sheet และรายงานจุดที่ต้องแก้

## Checklist ก่อนส่ง

- [ ] ทุกไฟล์ 256×256, PNG 8-bit RGBA, sRGB, ไม่มีพื้นหลัง ไม่มีเงาพื้น
- [ ] foot pivot (128, 228) ตรงทุกทิศทุกเฟรม เท้าแตะเส้น y = 228
- [ ] ภาพอยู่ในพื้นที่ปลอดภัย x/y 8–247
- [ ] ครบทุกทิศที่ต้องมี (N NE E SE S; arm_front ไม่มี S/N, hair_front ไม่มี N/NE) ไม่ต้องส่ง SW W NW
- [ ] idle และ walk มี 8 เฟรมพอดี ไฟล์ `000.png`–`007.png`
- [ ] ชุด หมวก อาวุธ หัว ผม วาดทับท่าพัก (idle เฟรม 0) พอดี
- [ ] อาวุธอยู่มือขวาของตัวละคร (ในทิศที่วาด)
- [ ] ไม่มีตัวอักษรหรือลายที่ต้องอ่านได้ (จะกลับด้านใน SW W NW) และภาพอยู่ใกล้เส้นกลาง x = 128
- [ ] body ใต้ชุดและใต้ผมวาดต่อให้ครบ (ถอดแล้วไม่มีรู)
- [ ] มีตำแหน่ง socket ทุกเฟรมของ body (manifest หรือ `sockets.csv`)
- [ ] ชื่อโฟลเดอร์และไฟล์ตามกฎใน 07 (ตัวพิมพ์เล็ก ไม่มีช่องว่าง ทิศตัวพิมพ์ใหญ่)
- [ ] ปิด guide และ overlay ก่อน export
- [ ] บอกสไตล์: `linear` (ภาพวาด) หรือ `nearest` (pixel art)

## สิ่งที่ต้องคุยกันก่อนวาด (ถ้ามี)

- ตัวละครสูงเกิน 256 px, อาวุธยาวมาก
- slot หรือ layer ใหม่ (ผ้าคลุม โล่ ปีก หาง แขนเสื้อแยก)
- กระโปรงหรือเสื้อคลุมยาวที่ต้องขยับตามขา
- ท่าที่แขนหมุนมาก (โจมตี) หรือท่าใหม่อื่นๆ
- สัดส่วนต่างจากตัวต้นแบบมาก (ต้องส่งตาราง socket ท่าพักของตัวเอง ดู 03)
