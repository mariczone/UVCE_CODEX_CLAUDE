# 02 · 8 ทิศ

## ทิศหมายถึงอะไร

ทิศในชื่อไฟล์คือ **ทิศที่ตัวละครหันไป เมื่อเทียบกับกล้อง** ไม่ใช่ทิศเหนือใต้ในแผนที่
engine เลือกภาพทิศที่ถูกต้องเองตามมุมกล้องและทิศที่ตัวละครหัน (กล้องหมุนแล้วภาพที่แสดงก็เปลี่ยนตาม)

| ทิศ | ตัวละครหัน… | สิ่งที่เห็น |
|---|---|---|
| **S** | เข้าหากล้องตรงๆ | หน้าเต็ม |
| **SE** | เข้าหากล้อง เฉียงไปทาง**ขวาของจอ** | หน้าสามในสี่ หันขวา |
| **E** | ไปทาง**ขวาของจอ** | ด้านข้าง หันขวา |
| **NE** | ออกจากกล้อง เฉียงไปทางขวาของจอ | หลังสามในสี่ หันขวา |
| **N** | ออกจากกล้องตรงๆ | หลังเต็ม |
| **NW** | ออกจากกล้อง เฉียงไปทางซ้ายของจอ | หลังสามในสี่ หันซ้าย |
| **W** | ไปทาง**ซ้ายของจอ** | ด้านข้าง หันซ้าย |
| **SW** | เข้าหากล้อง เฉียงไปทางซ้ายของจอ | หน้าสามในสี่ หันซ้าย |

- แต่ละทิศครอบคลุมมุม ±22.5° ตัวละครจึงเปลี่ยนภาพทุก 45°
- ดู `examples/sheets/directions-idle.png` (เรียง N NE E SE S SW W NW จากซ้ายไปขวา)
- **วาดแค่ 5 ทิศ: N, NE, E, SE, S** อีก 3 ทิศ (SW, W, NW) engine กลับภาพจาก SE, E, NE ให้เอง (ดูหัวข้อ mirror ข้างล่าง)
- ในทิศที่ต้องวาด ไม่ต้องส่งเฉพาะชิ้นที่ในทิศนั้นมองไม่เห็นเลยจริงๆ (เช่น arm_front ใน S/N, hair_front ใน N/NE ดู 05) ทิศที่ไม่ส่งจะไม่ถูกวาด

## มือขวา มือซ้าย (สำคัญมาก)

- "มือขวา" คือ **มือขวาของตัวละคร** ไม่ใช่ด้านขวาของจอ
- อาวุธอยู่ใน **มือขวา (socket `right_hand`)** เสมอ
- ผลที่ตามมา:
  - **S, SE:** ตัวละครหันเข้าหากล้อง มือขวาจึงอยู่ **ทางซ้ายของจอ** (เหมือนมองคนที่ยืนหันหน้ามาหาเรา)
  - **E, NE:** มือขวาอยู่ด้านใกล้กล้อง อาวุธจึงวาด**ทับ**ลำตัว
  - **N:** มือขวาอยู่ด้านไกลจากกล้อง อาวุธจึงอยู่**หลัง**ลำตัว
- ลำดับการวาดต่อทิศ (ตารางใน 03) ใช้หลักนี้ ถ้าวาดอาวุธผิดมือ ภาพจะซ้อนผิดชั้นทันที
- ทิศ SW / W / NW เป็นภาพกลับ อาวุธจึง**ไปอยู่มือซ้าย**ในทิศเหล่านี้ (ตกลงแล้วว่ายอมรับได้)

## Mirror: วาด 5 ทิศ ได้ 8 ทิศ

| ทิศที่ engine สร้างให้ | กลับภาพจาก |
|---|---|
| **W** | E |
| **SW** | SE |
| **NW** | NE |

- ทุก part ตั้ง `allowMirror: true` (ดู 07) และ**ไม่ต้องส่งไฟล์** W / SW / NW
- engine ใช้ภาพเดิมของ E / SE / NE แล้วกลับซ้ายขวารอบเส้นตั้งผ่าน foot pivot (x = 128) ตอนวาด จึง**ไม่เปลือง memory เพิ่ม** และลดงานวาดลง ~37%
- ตำแหน่ง socket, anchor และลำดับชั้นของทิศที่กลับ คำนวณจากทิศต้นทางให้เอง: pixel คอลัมน์ x กลายเป็น 255 − x
- ผลที่ต้องรู้ก่อนวาด (ยอมรับแล้ว):
  - อาวุธ / ของในมือขวา ใน W/SW/NW จะอยู่**มือซ้าย** และวาดทับลำตัวเหมือนใน E/SE/NE
  - ลาย ตัวอักษร โลโก้ ผมแสก จะ**กลับด้าน** ใน W/SW/NW ดังนั้นออกแบบให้ไม่สมมาตรน้อยที่สุด (เช่น ไม่ใส่ตัวอักษรบนชุด)
  - วาดชิ้นให้อยู่ใกล้เส้นกลาง x = 128 ภาพที่กลับแล้วต้องยังอยู่ในผ้าใบ (compiler ตรวจให้)
- ถ้าชิ้นไหนจำเป็นต้องไม่สมมาตรจริงๆ (เช่น ผ้าคาดไหล่ข้างเดียวที่ต้องอยู่ข้างเดิม) ส่งไฟล์ W / SW / NW ของชิ้นนั้นมาเองได้ **ไฟล์ที่ส่งมาเองชนะการกลับภาพเสมอ** (เฉพาะทิศที่ส่ง)
- ดู `examples/sheets/directions-idle.png` สามช่องขวาสุด (SW W NW) คือภาพกลับ สังเกตเลข 1 บนเสื้อและหมวกกลับด้าน

## ความสม่ำเสมอระหว่างทิศ

- สัดส่วน ความสูง ความกว้างไหล่ และตำแหน่ง foot pivot ต้องเท่ากันทุกทิศ
- แสงและเงาในตัวควรมาจากทิศเดียวกันในทุกทิศ (แนะนำ: แสงจากด้านบนเฉียงซ้ายของจอ) ไม่ใช่หมุนไปตามตัวละคร
