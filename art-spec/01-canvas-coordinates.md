# 01 · ผ้าใบ พิกัด และสเกล

## ผ้าใบ (canvas)

- ทุกไฟล์มีขนาด **256 × 256 px พอดี** compiler จะปฏิเสธไฟล์ขนาดอื่น (error `png.size`)
- **ไม่ต้อง crop เอง:** compiler ตัดขอบโปร่งใสออกและจำตำแหน่งเดิมไว้ให้เอง การส่งผ้าใบเต็มขนาดจึงไม่เปลืองอะไร
- จุด (0, 0) อยู่ **มุมซ้ายบน** แกน x ไปทางขวา แกน y **ลงล่าง** หน่วยคือ pixel ของภาพต้นฉบับ
- ทุก layer ของตัวละครเดียวกันใช้ผ้าใบขนาดเดียวกันและพิกัดเดียวกัน: pixel (x, y) ของทุกไฟล์หมายถึงจุดเดียวกันบนตัวละคร

## จุดอ้างอิงเท้า (foot pivot)

- **foot pivot = (128, 228)** คือจุดที่ตัวละคร "ยืน" อยู่บนพื้นโลก 3D
- วางให้ **ฝ่าเท้าแตะเส้น y = 228** และ **กึ่งกลางระหว่างเท้าสองข้างอยู่ที่ x = 128**
- พื้นที่ใต้เส้น y = 228 (ราว 20 px) เผื่อไว้สำหรับรองเท้า ส้นเท้า หรือเท้าที่ก้าวลงต่ำกว่าเส้นเล็กน้อยในท่าเดิน ส่วนอื่นห้ามวาดต่ำกว่าเส้นนี้
- **ห้ามวาดเงาบนพื้น:** engine วาดเงาวงรีใต้เท้าให้เองตามตำแหน่งในฉาก ถ้าวาดเงามาในภาพ จะได้เงาซ้อนสองชั้นและเงาจะลอยตามตัว
- ในทุกทิศ ตัวละครต้องยืนบน foot pivot จุดเดิม (ไม่ใช่ขยับให้อยู่กลางภาพตามรูปทรงของทิศนั้น) ไม่เช่นนั้นเวลาหมุนตัวจะดูกระโดด
- engine ใช้จุดนี้คำนวณลำดับการวาดระหว่างตัวละคร (ตัวที่เท้าอยู่ใกล้กล้องกว่าวาดทีหลัง) และการบังกับวัตถุ 3D ถ้าเท้าไม่อยู่ที่ pivot ตัวละครจะดูลอยหรือจมพื้น

## สเกล

- **128 px = 1 เมตร** ในโลก 3D (`pixelsPerWorldUnit = 128`)
- ตัวต้นแบบสูงราว 180–200 px จากเท้าถึงหัว ≈ 1.4–1.56 m หัวอยู่ราว y = 30–50
- ทุกตัวละครที่จะอยู่ในฉากเดียวกันควรใช้สเกลเดียวกัน ตัวที่สูงกว่าก็วาดสูงกว่าตามจริงบนผ้าใบขนาดเดิม
- ถ้าตัวละครหรืออาวุธยาวจนเกินผ้าใบ 256 px (เช่นหอกยาว) ให้แจ้งก่อนวาด rig รองรับผ้าใบขนาดอื่นได้ แต่ทุกชิ้นต้องเปลี่ยนพร้อมกัน

## พื้นที่ปลอดภัย (safe area)

- วาดให้อยู่ภายใน **x 8–247 และ y 8–247** (เว้นขอบ 8 px ทุกด้าน)
- ถ้ามี pixel ไม่โปร่งใสที่ขอบผ้าใบ: compiler เตือน `png.touches-border` เพราะภาพอาจถูกตัด
- ถ้าขอบผ้าใบมี pixel ไม่โปร่งใสเกินครึ่ง: error `png.matte` เพราะน่าจะติดพื้นหลังมา

## ภาพนำทาง

- `templates/guide-<DIR>.png` ใช้เป็นพื้นหลังตอนวาด: กริด 16 px (เส้นเข้มทุก 64 px), กรอบปลอดภัย, เส้นพื้น y = 228 (เขียว), เส้นกึ่งกลาง x = 128, กากบาทที่ foot pivot และจุดสี socket ของท่าพักในทิศนั้น
- `templates/overlay-<DIR>.png` คือเส้นชุดเดียวกันบนพื้นโปร่งใส ใช้วางเป็น layer บนสุดเพื่อเช็คตำแหน่ง
- **ก่อน export ต้องปิด guide และ overlay** ห้ามให้ติดไปกับไฟล์ที่ส่ง
