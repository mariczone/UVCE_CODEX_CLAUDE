# 04 · ท่าทาง (animation)

## วาดอะไรบ้างต่อเฟรม

| ชิ้น | วาดกี่ภาพ |
|---|---|
| `body` และ `arm_front` | **ทุกเฟรม ทุกทิศที่วาด ทุกท่า:** 5 ทิศ × (idle 8 + walk 8) = 80 ภาพต่อ layer (arm_front มี 3 ทิศ NE E SE = 48 ภาพ) อีก 3 ทิศ engine กลับภาพให้ (ดู 02) |
| `head`, `hair_*`, `armor`, `hat`, `weapon` | **1 ภาพต่อทิศ × 5 ทิศ** (ในท่าพัก) engine เลื่อนตาม socket ของ body เองทุกเฟรม |

นี่คือหลักที่ทำให้เปลี่ยนชุดได้สดโดยไม่ต้องวาดชุดใหม่ทุกท่า: ท่าใหม่หนึ่งท่าต้องวาดเพิ่มแค่ body

## ท่า idle

| ค่า | |
|---|---|
| id | `idle` |
| จำนวนเฟรม | **8** (ไฟล์ `000.png` – `007.png`) |
| เวลาต่อเฟรม (ms) | 180, 120, 120, 180, 180, 120, 120, 180 (รวม 1,200 ms) |
| วนลูป | ใช่ (เฟรม 7 ต่อกลับไปเฟรม 0 ได้เนียน) |
| ลักษณะ | หายใจ ตัวขึ้นลงเบาๆ 1–2 px เท้าอยู่กับที่บน foot pivot |
| เฟรม 0 | = **ท่าพัก** ที่ใช้วาดชุดและอาวุธทั้งหมด และเป็นค่า `restSockets` ของ rig |

## ท่า walk

| ค่า | |
|---|---|
| id | `walk` |
| จำนวนเฟรม | **8** (ไฟล์ `000.png` – `007.png`) |
| เวลาต่อเฟรม (ms) | 100 ทุกเฟรม (รวม 800 ms ต่อรอบ = 2 ก้าว) |
| วนลูป | ใช่ |
| event | `footstep` ที่ 0 ms และ 400 ms ⇒ **เฟรม 0 และเฟรม 4 คือจังหวะเท้าแตะพื้น** |
| ลักษณะ | เดินอยู่กับที่ (in place) **ห้ามเลื่อนตัวไปข้างหน้าในภาพ** engine เป็นคนเลื่อนตัวละครในโลกเอง |

- จุดกึ่งกลางเท้าต้องวนอยู่รอบ foot pivot ตลอดรอบ ถ้าทั้งตัวเลื่อนออกไป ตัวละครจะดูไถลบนพื้น
- จำนวนเฟรมต้อง**ตรงพอดี** ถ้าทิศไหนมี 7 หรือ 9 เฟรม compiler จะ error `part.frame-count`

## Socket ต่อเฟรม (บังคับสำหรับ body)

- ทุกเฟรมของ `body` ต้องระบุ **ทั้ง 6 socket** ของเฟรมนั้น (head_top, neck, chest, right_hand, left_hand, back) ถ้าขาดจะ error `frame.sockets`
- ชิ้นอื่นห้ามระบุ socket มีแค่ body (socket driver) ที่ระบุได้
- engine ใช้สูตร: **ตำแหน่งชิ้นในเฟรมนี้ = ตำแหน่งที่วาด + (socket ของเฟรมนี้ − anchor ของชิ้น)**
  เช่นในเฟรมที่หัวตกลง 2 px, socket `neck` ก็ต้องลง 2 px หัวและผมจะลงตามเอง
- socket ต้องอยู่ตรงจุดเดียวกันบนร่างกายทุกเฟรม เช่น `right_hand` = กลางกำมือขวาเสมอ เมื่อมือแกว่ง จุดก็แกว่งตาม
- ดูตัวอย่าง: `examples/sheets/walk-SE-sockets.png` (เลขบนภาพ = เลขเฟรม จุดสี = socket ของเฟรมนั้น)
- วิธีส่งค่า socket: ดู 07 (เขียนใน manifest หรือส่งเป็นตารางให้ผมแปลงก็ได้)

## ข้อจำกัดที่ควรรู้

- ชุด หมวก และอาวุธ **เลื่อนตามได้อย่างเดียว ไม่หมุนหรือบิดตาม** ท่าที่แขนหมุนมากๆ (เช่นฟันดาบ) จะทำให้อาวุธไม่หมุนตามมือ ท่าแบบนั้นต้องคุยกันก่อน (ต้องมีภาพอาวุธต่อเฟรม หรือ rig แบบอื่น)
- ไม่ต้องวาดผมหรือผ้าที่ปลิวตามจังหวะ (secondary motion) ตอนนี้ engine ยังไม่รองรับ (แผน Milestone 4)
- ต้องการท่าเพิ่ม (วิ่ง, โจมตี, ตาย) ให้แจ้ง id, จำนวนเฟรม และเวลาต่อเฟรม ก่อนวาด
